# malorytest
Malory demo test repository

## Project Goals

Serve as a small demo and test repository for Malory. The current `main` branch is README-only; proposed scripts are not yet part of it.

## Getting Started

You need Git installed and a GitHub account with authorized access to this private repository. Configure [HTTPS authentication](https://docs.github.com/en/get-started/git-basics/caching-your-github-credentials-in-git) before cloning; keep credentials out of the clone URL.

```sh
git clone https://github.com/dt665m/malorytest.git
cd malorytest
```

## FAQ

### What tools do I need to get started?

You need Git to clone the repository. No runtime is needed for the README-only `main` branch.

### Why can't I clone the repository?

This repository is private. Your GitHub account needs repository access, and Git must authenticate with that account. See [GitHub's clone troubleshooting guide](https://docs.github.com/en/repositories/creating-and-managing-repositories/troubleshooting-cloning-errors).

### Where are the scripts?

Scripts are proposed in [open pull requests](https://github.com/dt665m/malorytest/pulls); they have not landed on `main`. Check each pull request's files and instructions before trying its proposed code.

## Contributing

1. Start from up-to-date `main` and create a branch: `git switch -c your-change`.
2. Make your change, review the diff, and run any relevant checks.
3. Commit your change and push your branch: `git push -u origin your-change`.
4. Open a pull request targeting `main`, describing the change and how you validated it.

## Support

For questions or bug reports, [open a GitHub issue](https://github.com/dt665m/malorytest/issues) in this repository. Include:

- A clear title and a description of your question or problem.
- For bugs, steps to reproduce, expected behavior, and actual behavior.
- Relevant environment details, such as your operating system and tool versions.
- Relevant logs, error messages, or screenshots, with secrets and personal information removed.
